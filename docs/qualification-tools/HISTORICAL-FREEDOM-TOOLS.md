# Historical Freedom qualification tooling

[HISTORICAL-FREEDOM-SOURCES.json](HISTORICAL-FREEDOM-SOURCES.json) preserves the 360 tracked Railgun script paths from Freedom commit `860c680f635fc5941b4b3bad8295bbad9315199f`. There are 327 exact historical copies under `tools/freedom-legacy-qualification/`; the other 33 already have byte-identical destinations in the package's qualification tools. Each row records its original Git blob, SHA-256, length, mode and destination. No original source has been deleted by this preservation step.

These are historical recipes tied to the original Freedom source layout, host services and pinned inventories. They are **not portable installed-package commands**, and copying them does not qualify them against the current package. Do not run them by rewriting paths, importing private package owners, or weakening their source checks. Reproduce an old campaign at its original source revision with its recorded inputs, or use a separately reviewed installed-package successor. Old campaign results retain their original scope and commit.

The historical tree is excluded from the npm files list, public export map and default test discovery. It contains public fixture source, including deliberately public test credentials and dummy proofs, but no wallet profile, dependency installation, engine/prover artifact or generated campaign output. Some original tools describe live operations: their presence is not authorization to contact services, disclose an owned note or spend funds.

Active protocol tests live in `test/` and the explicitly admitted owner test groups. Freedom retains its actual credential, platform, context, storage, journal and application-composition acceptance checks. Newly qualified installed-owner recipes prove the moved protocol code through those fixed host services. Historical source preservation and active test migration are separate obligations; this manifest alone authorizes neither source removal nor a claim that all 360 files execute in this repository.
