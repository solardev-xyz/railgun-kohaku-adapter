# Archived Freedom Railgun qualification

This directory preserves 1,165 historical qualification files (80,213,641 bytes)
from Freedom commit `6e2fe585b07fa02b255e5430f6f6c834b52409f2`.
The source is [solardev-xyz/freedom-browser](https://github.com/solardev-xyz/freedom-browser/tree/6e2fe585b07fa02b255e5430f6f6c834b52409f2/docs/qualification).
This is an ownership transfer of evidence, not a new qualification run or a claim
that the complete Railgun runtime has already been extracted.

[MANIFEST.json](MANIFEST.json) maps every preserved file to its original repository,
full commit, path, Git blob ID, SHA-256, byte length and mode. The destination
retains the original suffix under `docs/qualification/`. All listed payload bytes
and modes are unchanged. This README, the manifest and [NOTICE.md](NOTICE.md) are
new archive metadata and are not original observations.

## How to read the evidence

The archive spans source/mock checks, disposable synthetic fixtures, recorded
public-chain/service observations and native-process qualifications. Each original
record defines its own conditions and limits. Source hashes and original process
observations still refer to the historical Freedom checkout and external runtime
inputs; they do not authenticate today's installed package or a new run.

Some local relay campaigns deliberately substitute a synthetic trust list and
exercise local custody rather than live relay transport. A successful synthetic
case does not establish authentic service membership, production network success,
funded-account safety or arbitrary crash recovery. Failure records remain failures.
Read each campaign's original overview and report before using a result.

The archive is not a self-contained executable distribution. Engine/prover
archives, installed dependencies, profiles and external launcher inputs are not
made available merely because their hashes appear in a report. No profile or
untracked worktree files were copied during this transfer.

## Historical paths and links

Original source maps, reports, copied source text, commands and Markdown remain
byte-identical, including old repository-relative paths. Relative links among
preserved sibling files generally still work; links that leave the archive must
be interpreted at the original Freedom commit above. Use the manifest's
`originalPath` and `originalCommit` to resolve them. Do not silently rewrite a
historical hash inventory to describe the new layout or execute an archived
command as a current recipe.

Future Freedom integration tests can retain only their necessary public input
fixtures while linking here for the larger historical record. At this preparation
stage the original Freedom files have not been removed or changed.
