## Evidence and representation

`prepare-report.json` and `unchanged-list-report.json` are explicitly **derived**, not byte-exact originals. Each original report contained one absolute local SQLite filename in `cacheAfter.native`. Only that value was replaced with the dependency-relative name `better-sqlite3/prebuilds/darwin-arm64.node`; all report JSON values otherwise remain unchanged. JSON was reserialized. Each wrapper records its original byte count/SHA-256, matching the corresponding byte-exact `result` record.

The `result`, `post`, `main-process`, `driver-observation`, and three-line main logs are path-free byte-exact originals. Root driver observations are the parent's records of original process handles; they are not self-authenticating operating-system evidence. `bindings.json` records the independently checked joins, source/runtime/package pins, inventory counts, public input hash, and exact original request/source-freeze/resolver metadata hashes. Large source/dependency inventories and path-bearing requests are omitted; this compact archive cannot independently reconstruct or rerun them. It contains no profile payload, seed, viewing/spending key, archive binary, proving artifact or installed dependency tree.

Earlier failed attempts remain failures. Attempt **a** stopped after 64 utility jobs; a later source finding identified the fixture's missing public-address transaction-RPC admission, consistent with that boundary but not an original inner diagnostic. Attempt **b** completed 69 utility jobs and the preparation returned, but a fixture regex rejected the genuine `0x`-prefixed transaction digest. It had no qualified report/cache result. Both exact parent-retained summaries are included without retroactively turning either attempt into success. No failed profile was opened while producing this archive.

`report-contract.cjs` is the byte-exact r4 fixed report validator. Run `node verify.cjs` from this directory (or supply its repository-relative filename) to verify archived bytes, path exclusion, result/report/driver bindings and the fixed public report contract. This is offline metadata checking, not a new native or cryptographic qualification.
