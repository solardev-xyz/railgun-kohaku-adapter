# Fixed process and worker owner successor (inactive)

This bounded source successor replaces the translated legacy utility filename route with 36 package-private enums. It does not change package exports/version, install a package or activate the main owner. Historical TRANSLATION/PROVENANCE records remain unchanged. SOURCES.json records this implementation delta separately; the combined owner audit must update live-source expectations without claiming these files remain import-only translations.

The platform contract is the fixed Freedom adapter at 5fc4d853. `spawnUtility({entry:'railgun-utility-v1',heapMb})` returns the original child; `createUtilityChannel()` returns original ports; `memorySamples()` returns original metrics; `terminateUtility(originalChild, signal)` handles TERM/KILL. No path, argv, environment, entry callback or process options are passed. `applicationLifetime()` returns a genuine native AbortSignal. Admission checks its intrinsic aborted getter; synthetic events cannot trigger shutdown or consume the listener. Preaborted lifetime refuses before fork, including an abort during channel creation. After a child exists, only its original exit releases the slot and removes the application listener; requesting TERM/KILL or a timeout is insufficient.

The session-worker port receives only `{workerData,transferList}` using the original existing subject/requirements/storage/revocation fields and the original owned 32-byte ArrayBuffer. The platform chooses startup entry/environment/resource limits and drains stdout/stderr. The package keeps provider dispatch, monotonic messages, bytes/pending limits, revision observations, close escalation and original exit ownership. Copy/transfer failure wipes the owned copy; the caller's key is untouched. Worker application shutdown is similarly original-exit owned. The new private `host-owner-worker-bootstrap.cjs` requires actual worker realm and native parentPort brand before loading the existing private worker binding. `initialize({context})` binds once, then loads only the fixed session protocol. It is intentionally not added to package exports yet; the host storage stub cannot activate until the complete integration is reviewed.

Utility guards still install before host binding or any job import. Existing nine execution jobs are reused. The new cases use literal package-owned require targets; there is no filename resolver, generic loader or new callback capability. Keyless jobs receive a rejecting requestKey function. Host admission independently enforces role/operation/key classification and rejects filename/binaryKey options even when a valid enum is also present. One-key request id/purpose matching and wipe behavior, 64 KiB input, original message limits, 120-second startup cap, lifetime/RSS limits and borrowed broker ownership remain.

## Eligibility comparison and intentional narrowing

All eight old key-capable kernel cases remain key-capable. Every old binary-key legacy branch has an exact enum: relay-sign; relay-pre-poi; relay-prove-local; relay-prepare and relay-reconstruct; poi-prove; poi-transact-selector; poi-output-recover; shield-receive. Private/relay/POI verifiers and other computation remain keyless. The 36-route tests and bootstrap capability matrix agree for every enum.

All routes now require genuine context kind private-account, Railgun/sepolia/11155111, the exact role and exact operation. Previously seven early kernel cases and the legacy poi-output-recover key branch did not explicitly restrict kind; every actual c6 owner caller already uses private-account. POI membership uses a fixed enum with the existing genuine role poi and exact lower-case `poi:<64hex>` operation domain. Seven TXID enums additionally join their input mode before importing the job. Other original jobs retain their internal data checks.

The old generic absolute filename route, its broker-optional development sessions, caller binaryKey opt-in and generic process-owned storage/provider selection are refused. Every actual c6 production owner call uses a borrowed broker. Standalone genuine session workers remain supported via their fixed port. Legacy qualification fixtures using arbitrary jobs need explicit replacement, not a bypass. No old generic route is retained as fallback. Some unreachable process-owned-session cleanup branches remain from the original implementation; admission cannot reach them.

A preaborted application lifetime returns a synchronous refusal rather than manufacturing a child/exit. Failure after channel creation but before fork returns the normal already-closed task with null exit and releases only an absent child. Once spawned, close remains pending until original exit. Borrowed broker owners still drain their original dispatches; this patch does not claim child exit proves broker drainage.
