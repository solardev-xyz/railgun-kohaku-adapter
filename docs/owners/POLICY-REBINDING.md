# Owner initialization policy identity

Source-only successor over 59c50995c6e2b555f4f217deccf9a234ea018db1. Earlier per-read draft remains frozen as 81711580c8cf2399e406c0c1091a5607222e00bb; it is superseded, not activated.

The paired private owner initializer captures package bytes and the fixed main host sourceIdentity.readDigest() value once, before publishing either owner binding. The source reader hashes 242 explicit runtime paths, including package.json, the list itself, root CJS/MJS entries and all tracked src JS/CJS/JSON/MJS. List membership has a fixed embedded SHA; the list contains names only, with no digest self-reference. Initialization checks fixed relative path syntax, sorted exact membership, canonical containment, ancestor/final symlink refusal, file type/size and total byte bounds. Failures have a path-free typed refusal and poison initialization. There is no runtime directory discovery or caller-selected path.

Subsequent policy reads require the genuine initialized owner and reuse the same immutable sources-v2 snapshot. They do not read disk or call the host digest again and cannot silently rotate generations within a running process. A newly initialized process captures changed bytes. This is conservative cache identity: it is not code trust, proof of equality to all loaded bytes, a full execution dependency graph, or ongoing tamper detection. Concurrent filesystem mutation during initialization is not claimed to be an atomic filesystem snapshot.

All three existing policy domain/schema strings, engine verification, QUALIFIED_THROUGH=11829346 and TXID store binding rules remain unchanged. Their hashed input now includes the package identity and the fixed host digest. Whole-package invalidation is intentional for this milestone: unrelated package/host changes can invalidate wallet/public/TXID generations, require rescans from the historical qualification floor and rebuild TXID mirrors. Generations are host-specific. Old encrypted generations remain untouched and consume disk/privacy retention; no deletion, pruning or profile migration is implemented.

Generate/check membership with `python3 tools/generate-owner-source-list.py [--check]`. Record this reversible policy transform with `TYPESCRIPT_PATH=... python3 tools/record-owner-policy.py`. POLICY-TRANSITIONS is inverted before SIGNER-LIFETIME, CALLER, PROCESS and original provenance layers. Original policy source text is retained in HISTORICAL-POLICY-SOURCES; retired generic process entry remains only in its byte-exact historical fixture and is excluded from this runtime list. Ordinary data and POI helpers stay bootstrap-independent.

## Remaining integration gates

This is a staged list, not final packed-membership evidence. Root authority/worker/journal entries remain unexported or absent from package.files until deliberate activation. Final root entries, exports, worker/facade additions and source membership changes require regeneration and generator --check before packaging. Edited bytes already in the list automatically affect the next process snapshot. Host digest implementation and startup composition are parent-owned (host adapter source42d914d3); this source-only check does not assert its runtime output or native asar path compatibility. No package exports/version/dependency changes, owner activation, engine/prover execution, native utility/profile work or publication occurred.
