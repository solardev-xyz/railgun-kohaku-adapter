# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/solardev-xyz/railgun-kohaku-adapter/security/advisories/new)
for suspected vulnerabilities in this adapter or its reference host. Private
reporting is enabled for this repository. Do not open a public issue containing
an exploit against funded custody or account-linked evidence.

Include the adapter commit/tar identity, affected component, environment and a
minimal reproduction using disposable public fixtures where possible. Never send
mnemonics, passwords, private keys, funded profile directories, raw proofs or
linked private transaction histories. A private channel does not make those
materials necessary or safe to disclose. Agree on any sensitive reproduction
material with maintainers first.

This is experimental software without a completed independent security audit,
production support commitment or guaranteed response time. Reports concerning
upstream Railgun/Kohaku dependencies may require coordinated disclosure with
their maintainers; do not assume this repository represents those projects.

If the private-report form is unavailable, open an issue asking only for a private
contact route, without vulnerability details or account information. Do not send
funds or disclose custody to demonstrate a bug.
